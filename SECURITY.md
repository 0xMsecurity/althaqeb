# Security Policy — الثاقب (Althaqeb)

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | ✓ Current |

## Responsible Disclosure

If you discover a security vulnerability in Althaqeb itself, please report it responsibly:

**Email:** msecurity@msecurity.bh  
**GitHub:** Open a private security advisory at https://github.com/0xMsecurity/althaqeb/security/advisories/new

Please **do not** open a public issue for security vulnerabilities.

## What to Report

- Vulnerabilities in Althaqeb's own codebase
- Payload injection risks in the report generator
- Authentication/authorization issues in the API server
- Dependencies with known CVEs

## Out of Scope

- Issues with target AI systems you are testing (that's the point)
- Vulnerabilities in third-party dependencies not yet patched upstream

## Acknowledgements

We are grateful to researchers who practice responsible disclosure.
